Alchemical Artisans
===================

Website for Alchemical Artisans, a two-person technology consulting practice. The
site is a working journal: notes from engagements, patterns we keep running into,
and the occasional opinion that has earned its keep. It also covers what we do
(architecture reviews, modernisation of legacy systems, cloud and platform work,
data engineering, and accessibility) and how to get in touch.

## Built With

- Jekyll
- HTML
- CSS / Sass
- Bootstrap-free custom theme (extends the Minima base)


## Structure

- `_posts/` — the workshop journal
- `_layouts/`, `_includes/` — theme overrides on top of Minima
- `assets/css/palette.css` — the Alchemical Artisans colour system
- `assets/main.scss` — the site theme
- `accessibility.md`, `about.markdown` — standalone pages
